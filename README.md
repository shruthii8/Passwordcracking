# Password Cracking
Password Cracking & Password Security Assessment

1. Project Overview

This project focuses on understanding password security through practical exercises in an authorized cybersecurity training environment.

The objective was to explore password hash extraction, password recovery techniques, and security tools while understanding the risks associated with weak and predictable passwords.

2. Objectives

Understand password hashing concepts.

Learn about password-protected PDF files.

Explore John the Ripper and Johnny GUI.

Understand password hash extraction.

Explore NetworkWalks password security tools.

Understand dictionary-based password testing.

Learn the importance of strong password practices.

3. Tools & Technologies

John the Ripper (JTR)

Johnny GUI

NetworkWalks Hash Calculator

NetworkWalks Password Cracker

Windows / Kali Linux (as applicable)

PDF Reader

4. Practical Modules

Module 1 – John the Ripper & Johnny

Explored the John the Ripper password auditing tool.

Practised PDF password hash extraction.

Worked with Johnny GUI.

Performed password recovery in the authorized training environment.

Verified the results.

Module 2 – NetworkWalks Password Tools

Explored the NetworkWalks Hash Calculator.

Studied password hash information.

Used the NetworkWalks Password Cracker.

Practised dictionary-based password testing.

Observed password security weaknesses.

5. Key Learning Outcomes

Understanding password hashes.

Practical exposure to password auditing tools.

Understanding dictionary-based password testing.

Recognizing weak password vulnerabilities.

Importance of strong and unique passwords.

Understanding responsible cybersecurity practices.

6. Security Recommendations

Use strong and unique passwords.

Enable multi-factor authentication.

Avoid password reuse.

Use secure password storage mechanisms.

Conduct password security assessments only with proper authorization.

7. Conclusion

This Week 3 project provided valuable practical exposure to password security, hash analysis, and password recovery techniques.

It strengthened my understanding of how cybersecurity professionals assess password security and identify weaknesses in authentication practices.

Learning through practice. Building skills one project at a time!
